# Frogger-Game
Code for the classic game "Frogger" in python, using simple visuals and the turtle library

Includes the menu tab and the main-code tab. It's a simple game with not fancy visuals but a classic and a good code challenge.
Needs the turlte library, no other installation required.

In the near future, a working timer will be added so that, if the player fails to get into a house in that time, he loses one life.
Also, I am working on putting some real animations instead of simple, static gifs.
